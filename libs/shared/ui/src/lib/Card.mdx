<h2 className='doc-section'>Padding</h2>

<p className='doc-p'>
  The <code>padding</code> prop controls spacing on the root <code>Card</code>.
  Sub-components don't add their own padding — this avoids double-padding issues
  and gives you full control.
</p>

<h2 className='doc-section'>Elevated vs Flat</h2>

<p className='doc-p'>
  Use <code>elevated</code> to raise a card above the default surface. This is
  useful for cards that need visual prominence or to separate a card from a busy
  background. The default flat style uses <code>bg-surface-elevated</code>;
  elevated uses <code>bg-surface-elevated</code>.
</p>

<div className='doc-do-dont'>
  <div className='doc-do'>
    <div className='doc-do-label'>Do</div>
    <p className='doc-do-body'>
      Use <code>elevated</code> to highlight a featured item in a grid of cards,
      or for cards that sit on top of a colored section.
    </p>
  </div>
  <div className='doc-dont'>
    <div className='doc-dont-label'>Don't</div>
    <p className='doc-dont-body'>
      Don't elevate every card. If everything is elevated, nothing stands out.
      Use it as an exception, not the default.
    </p>
  </div>
</div>
